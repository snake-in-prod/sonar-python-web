An endpoint that changes data (PUT, PATCH or DELETE; POST when it writes or runs a command on the server; a Django view open to any method when it writes) does not check who calls it, while other endpoints of the same app do. Anyone who can reach the server can create, change or delete the data it handles.

The rule counts as a check: a FastAPI auth dependency (Depends(get_current_user), Security(...), a fastapi.security scheme, a dependency that reads a credential) on the route, a parameter, the router, the include_router call or the app; Django login_required, permission_required, user_passes_test, auth mixins, method_decorator on the view or its dispatch, wrappers in urls.py, LoginRequiredMiddleware; DRF permission_classes, get_permissions and DEFAULT_PERMISSION_CLASSES; Flask login_required, jwt_required and similar decorators and before_request guards; aiohttp_security check_authorized, check_permission and authorized_userid, an aiohttp_session login check and an auth middleware registered on an aiohttp app; a check of the user, a token, a key or a signature in the handler or a helper it calls.

It stays silent for apps that check no caller anywhere, endpoints made open explicitly (AllowAny), endpoints that are public by purpose (login, signup, token, password reset, webhooks, callbacks, health), a POST that writes nothing and runs no command, and apps whose authentication sits where the analysis does not look (auth middleware).

Noncompliant code example

router = APIRouter(prefix="/items")

@router.delete("/{item_id}")
def delete_item(item_id: int, db: Session = Depends(get_db)):  # Noncompliant
    db.delete(db.get(Item, item_id))
    db.commit()

@require_POST
def delete_note(request, pk):  # Noncompliant
    Note.objects.filter(pk=pk).delete()

Compliant solution

@router.delete("/{item_id}")
def delete_item(item_id: int, user: User = Depends(get_current_user), db: Session = Depends(get_db)):
    ...

@require_POST
@login_required
def delete_note(request, pk):
    Note.objects.filter(pk=pk, owner=request.user).delete()
