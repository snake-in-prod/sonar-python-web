A default value written as [], {}, set() or another mutable object is created once, when the module is imported, and then shared. This rule reports such defaults where the sharing is a defect:

  • a parameter of a Django or Flask endpoint that the view changes in place: Django and Flask call the view with the default itself, so every request (of every user) sees and changes the same object;
  • a field of an attrs class (attr.ib(default=[]), attrs.field(default={}), or an annotated attribute of an @attrs.define class): every instance gets the same object;
  • the default of a Django JSONField, ArrayField or HStoreField: every new model instance gets the same object until it is saved and loaded again;
  • a field of a standard library @dataclass: the class raises ValueError when the module is imported.

Pydantic models and the parameters of FastAPI endpoints are not reported: Pydantic and FastAPI copy their defaults for each instance and each request. Parameters that the view only reads, or rebinds before changing, are not reported either.

Noncompliant code example

@app.route("/visit")
def visit(seen={}):  # Noncompliant: the same dict for every request
    seen[request.remote_addr] = True
    return jsonify(sorted(seen))


class Post(models.Model):
    meta = models.JSONField(default={})  # Noncompliant


@attrs.define
class Cart:
    items: list = []  # Noncompliant

Compliant solution

@app.route("/visit")
def visit(seen=None):
    seen = {} if seen is None else seen
    seen[request.remote_addr] = True
    return jsonify(sorted(seen))


class Post(models.Model):
    meta = models.JSONField(default=dict)


@attrs.define
class Cart:
    items: list = attrs.field(factory=list)
