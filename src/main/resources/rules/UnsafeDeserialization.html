Deserializing request data or an uploaded file with a format that can build any object runs code chosen by the caller: a pickle stream can call os.system while it is loaded. This rule follows request inputs, uploaded files (Django request.FILES, FastAPI UploadFile, Flask request.files) and cookies across functions and modules to pickle, dill, marshal, jsonpickle.decode(), joblib.load(), pandas.read_pickle(), numpy.load(allow_pickle=True), yaml.unsafe_load() and yaml.load() with an unsafe loader.

yaml.load() with a SafeLoader, CSafeLoader, BaseLoader or FullLoader (or a class named like one), yaml.safe_load(), json and data that comes from the server itself (a cache, a signed value) are not reported. The issue names the endpoint and shows the path from the input to the call.

Noncompliant code example

def restore(request):
    state = pickle.loads(request.body)  # Noncompliant

@app.post("/models")
async def upload_model(file: UploadFile):
    model = pickle.loads(await file.read())  # Noncompliant

Compliant solution

Exchange data as JSON, or YAML read with yaml.safe_load(), and validate it with a schema.

def restore(request):
    state = json.loads(request.body)

@app.post("/config")
async def upload_config(file: UploadFile):
    config = yaml.safe_load(await file.read())
