Template engines escape what they render. Request data that skips the escaping is cross-site scripting: passed to Django mark_safe or markupsafe.Markup, put in an HTMLResponse, or returned in a string by a FastAPI endpoint declared with response_class=HTMLResponse, or returned by a Flask view in a string holding an HTML tag (return f"<h1>Hello {name}</h1>": Flask sends a string as text/html), or written in a string holding an HTML tag that a Django HttpResponse (or HttpResponseBadRequest, HttpResponseNotFound...) sends as HTML (HttpResponse(f"<p>{q}</p>")). Request data used as the template source itself (render_template_string, jinja2.Template, Environment.from_string, django.template.Template) is worse: template injection runs code on the server.

The issue names the endpoint the data comes in through and shows its path to the call.

Noncompliant code example

@app.route("/hello")
def hello():
    return render_template_string("Hello " + request.args["name"])  # Noncompliant

@app.get("/hello", response_class=HTMLResponse)
def hello(name: str):
    return f"<h1>Hello {name}</h1>"  # Noncompliant

Compliant solution

@app.route("/hello")
def hello():
    return render_template_string("Hello {{ name }}", name=request.args["name"])

@app.get("/hello", response_class=HTMLResponse)
def hello(name: str):
    return f"<h1>Hello {html.escape(name)}</h1>"

When the rule stays silent

  • The value is escaped first: html.escape, django.utils.html.escape, markupsafe.escape, Markup.escape, bleach.clean, nh3.clean.
  • The value goes through format_html, Markup("...") % value, or is passed to the template as a variable.
  • The value is a FastAPI parameter typed int or another scalar.
  • The HttpResponse has a content_type that is not HTML (text/plain, JSON) or that the code computes, its string holds no tag, or it is a JsonResponse.
  • The value is a URL parameter that cannot hold markup: a converter other than str and path, a regex group of letters, digits and spaces ((?P<name>[a-zA-Z]+)), or a view argument given by kwargs= of path() rather than by the URL.
